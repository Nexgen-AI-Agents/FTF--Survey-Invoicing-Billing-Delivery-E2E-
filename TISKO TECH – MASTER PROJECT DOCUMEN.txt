One addition I would make

Since Tisko Tech is building AI OS, AI Agents, SaaS platforms, automations, websites, CRMs, and enterprise software, I would add a third folder:
03_Project_Assets

This would contain non-document deliverables that are referenced by both the client and internal teams, such as:
Logos & branding
UI assets
Wireframes
Figma exports
API collections (e.g., Postman)
Sample datasets
Prompt libraries
SOPs
Training videos
Demo recordings
User manuals
Release notes
Source file references

This keeps the repository clean by separating documents from project assets, making it easier to navigate and maintain as projects grow.
